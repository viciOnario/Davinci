API de Rentas

Gestión de propiedades, rentas, reseñas y usuarios

📌 Endpoints

👤 Usuarios
  • GET /api/usuarios
    Listar todos los usuarios
  • GET /api/usuarios/:id
    Usuario por ID
  • POST /api/usuarios
    Crear usuario
  • PUT /api/usuarios/:id
    Actualizar usuario
  • DELETE /api/usuarios/:id
    Eliminar usuario
🏢 Propiedades
  • GET /api/propiedades
    Listar todas las propiedades
  • GET /api/propiedades/:id
    Propiedad por ID
  • POST /api/propiedades
    Crear propiedad
  • PUT /api/propiedades/:id
    Actualizar propiedad
  • DELETE /api/propiedades/:id
    Eliminar propiedad
📑 Rentas
  • GET /api/rentas
    Listar todas las rentas
  • GET /api/rentas/:id
    Renta por ID
  • POST /api/rentas
    Crear renta
  • PUT /api/rentas/:id
    Actualizar renta
  • DELETE /api/rentas/:id
    Eliminar renta
⭐ Reviews
  • GET /api/reviews
    Listar todas las reseñas
  • GET /api/reviews/:id
    Reseña por ID
  • POST /api/reviews
    Crear reseña
  • PUT /api/reviews/:id
    Actualizar reseña
  • DELETE /api/reviews/:id
    Eliminar reseña
